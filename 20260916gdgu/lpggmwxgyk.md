# 胡某宇事件之后，我们应该做什么？

> 更新时间：2026-09-16 (UTC+8)

持续关注了一百多天的胡某宇事件，在昨天的新闻发布会上尘埃落定。

一个在同学眼中被评价为“内向、话少、成绩好”的孩子，在初三中考还没结束就被当地一较好的高中提前“锁定”了的优秀学生。在上了高中后，开始感受到学业的压力和自己的不适应，又因为自己不擅社交，不知如何找人倾诉、宣泄情绪和向外求助，只能是在书本、笔记本上书写下自己的经历与情绪。

而其中艰难无助的情绪，就像一个小雪球，越滚越大，当被压得喘不过气来之后，孩子选择了结束自己的生命。让我们替他惋惜的同时，也感受到了他的绝望。

逝者安息，其背后反映的**青少年心理健康问题**更值得我们思考和关注。

儿童青少年心理健康问题，一直备受我们关注。中国每年约有**10万**的青少年死于自杀，有**14%-20%**的青少年，在过去的一年中曾经出现过自杀的观念。**“抑郁”“emo”“泪失禁体质”**这些词语在儿童青少年中其实并不陌生。

青少年本身处于叛逆期，学业压力、亲子矛盾等引发的心理冲突已经成为学生群体普遍的问题。学校和家庭如果没有及时引导，反而采取了偏激的教育方式，则更容易适得其反。

搜索信息、网络宣泄、情绪反常、悲观倾向、兴趣降低、近期频繁遇到重大危机、整理东西、长期高压，如果青少年身上出现这样的情况，可能是在发出求救的信号。

我们需要及时识别并帮助这一群陷入情绪中无法自救的孩子。在这类孩子的身上，往往存在以下几种情况：

**0****1****变故（应激因素）**
孩子往往在经历一些变故，比如突如其来的疾病、更换学校、家庭变故等，继而引发焦虑抑郁情绪。胡同学正是因为由初中生转变为高中生，学业的压力让他开始逐渐不能适应，变得焦虑，对自己失去了信心而得不到排解从而导致了悲剧。

**0****2****表现 **
有焦虑抑郁情绪甚至自伤自杀观念的青少年，TA们往往在生活中出现了改变，能够为我们提供线索。与以往相比，TA们可能会：

1. 话少，不愿主动社交，更愿自己一个人待着

2. 自我评价低，容易自责、自罪，TA们往往会说“都是因为我不好”“如果没有我，事情也不会变成这样”

3. 觉得生活无趣，活动减少，甚至以往的兴趣爱好对他们也失去了吸引力

4. 食欲变差或吃得更多，体重明显地下降或增重

5. 睡眠质量下降，入睡困难、失眠、多梦、早醒，甚至黑白颠倒

6. 注意力不集中，思想涣散，成绩波动明显

7. 性格变化：焦虑、敏感易哭、多疑、情绪暴躁、冲动易怒等

8. 多有消极语言“我真没用”“我死了也无所谓”“没人在乎我”“如果我死了，父母也就不会有拖累了”等等

9. 伤害自己身体（割腕）、一次性口服大量药物等

**如果您周围的儿童青少年有4条以上这些表现时，可以这样做——**
**0****1**

**主动的交流**

很多家长会在门诊中告诉医生，青春期孩子“叛逆”，说什么都顶嘴，说什么都不听，甚至有些孩子明确和父母说“我不愿和你们说，我只愿意和医生说”。那么如何才能和孩子建立有效的交流呢？

**家长可以这样说：**

1. 我看到（感受到）你目前情绪有些不一样，你愿意和我说一说么？

2. 我观察到你最近睡眠/胃口变差了，愿意告诉我发生什么事了么？

3. 最近过得怎么样？心情如何？

4. 如果你愿意，我们一起去找心理医师寻求帮助，好么？

5. 你受这样的情绪困扰，并不是你的错，我们一起想办法解决

**不建议说的：**

1. 你不要那么敏感，想那么多干嘛？（忽视了孩子的情绪）

2. 我辛辛苦苦工作供你上学，你有什么好抑郁的？（否定孩子的情绪，并加强了孩子的负罪感）

3. 你学习认真点，不要总想那些乱七八糟的（让孩子觉得自己不受重视，受重视的只是学业）

4. 别的同学不说压力大，就你说压力大？（让孩子觉得没人理解）

5. 你这样做对得起谁？（增加孩子的负罪感）

**0****2**

**倾听、理解**

如果对方愿意对我们诉说，我们要做的是认真地倾听，理解对方的处境，并且不做评价。在倾听的过程中，我们心中难免会产生一些自己的价值判断，否定也好，赞同也好，我们需要意识到这些来自于我们自己的立场，不应将其强加给诉说者。

在倾听的过程中还可以留意以下几点：TA有无关于自杀的具体计划或准备、TA最大的痛苦是什么、TA尚未实施自杀的牵绊是什么。

**0****3**

**直接询问**

当家长发现孩子身上已经存在自残的伤痕之后，尽量保持冷静，可以询问孩子伤害自己的原因、发生的频率，同时可以直接询问TA是否有自杀的念头。

大量研究证明，询问关于自杀的问题并不会增加人们关于自杀的念头及行为。相反，直接讨论关于自杀的想法，对于一些有心理痛苦的人来说，是一个表达的出口。在生活中，当我们察觉到他人有上文所述的自杀征兆时，我们可以直接询问TA的具体想法，通过了解对方关于自杀的想法处在自杀意念、自杀计划、自杀准备中的哪个阶段，可以帮助我们判断其自杀风险的大小。

**0****4**

**寻求其他力量共同帮助**

当家长和孩子觉得目前的状态没有办法解决的时候，寻求其他力量共同帮助。比如可以找学校的心理老师进行心理疏导；到正规医院的心理科或精神科就诊，或是预约正规心理机构的心理咨询，还可以拨打各省市的心理援助热线取得即时的帮助。

我院儿童保健科开设**儿童青少年心理咨询门诊**，为儿童青少年及父母家长们提供心理咨询、沙盘心理技术、父母成长工作坊、家长课堂等心理卫生保健服务。
**0****5**

**做好陪伴 保障安全**

当孩子受着情绪困扰的时候，我们一定要做好陪伴，多倾听，陪伴，多进行一些户外运动。当TA被确认为决定自杀者时，在自杀风险解除之前，需对TA进行24小时监护。尤其要注意如刀片、圆规、钢尺、绳子、药片等物品的收纳，避免发生意外。

**0****6**

**自身情绪的调整**

很多家长在面对孩子的情绪问题之后，会自责、生气、愤怒，而家长的一言一行都会反作用在孩子身上，所以，作为家长，我们也需要照顾好自己的情绪，在面对孩子问题时，尽量帮助自己进行情绪稳定，或者用恰当的方式宣泄自己的情绪后，才才能更好的为孩子提供解决方法。

**希望每位家长都能对孩子多一份关心，多一份理解，帮助TA们在成长过程中更好地适应环境！**
