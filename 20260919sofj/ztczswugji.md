# 陕西妇幼保健院三代试管婴儿助孕详细流程是怎么样的

> 更新时间：2026-09-19 (UTC+8)

陕西妇幼保健院三代试管婴儿助孕详细流程是怎么样的，希望下面的内容能帮助大家对陕西妇幼保健院三代试管婴儿助孕详细流程是怎么样的有个正确了解。

在陕西妇幼保健院做第三代试管婴儿助孕首先需要对夫妻双方身体进行检查，明确不孕不育原因。没有太大问题就可以进周促排了，等到卵泡长到18-25mm时就可以打夜针取卵，取卵的同时取精，然后再将精子卵子结合培养5-6天养成囊胚。然后就采用PGS（移植前遗传学筛查）或PGD（移植前基因诊断）对囊胚进行筛查，选出健康的囊胚移植到女性体内，整个流程即结束。

陕西妇幼保健院生殖中心暨陕西省辅助生殖技术中心成立于2001年，该院目前已开展了夫精人工授精技术、助孕人工授精技术、常规体外受精-胚胎移植技术、卵胞浆内单精子显微注射技术、植入前胚胎遗传学诊断技术等，现陕西妇幼试管成功率稳定在60%左右，算是当地较佳的试管医院。而在该院做三代试管的具体流程如下：

- 1. 术前检查：夫妻双方做常规身体检查，女方做卵巢功能和子宫内膜检查，男方做精子常规检查；
- 2. 促排卵：即药物刺激超排卵技术，为了提高成功率，获得更多的较好的胚胎，则需要在一个周期中获得多个卵子；
- 3. 取卵：待卵泡发育成熟后，生殖医学专家在B超的引导下，将取卵针从引导侧壁穿刺至卵巢的成熟卵泡，吸出卵子；
- 4. 授精培养：将精子与卵子结合，然后进行养囊，一般5-6天就能形成囊胚；
- 5. 筛查：PGS一次性检测胚胎23对染色体的结构和数目，PGD是基因检测，以便使体外授精的试管婴儿避免一些遗传疾病；
- 6. 胚胎移植：用很细的导管经宫颈进入子宫，然后将胚胎通过导管注入宫腔；
- 7. 验孕：移植后，卧趟48小时可下床活动，12天左右可以用试纸验孕，14天返院抽血验孕。

以上就是陕西妇幼保健院三代试管婴儿助孕详细流程，目前在陕西妇幼做试管费用在4-10万元不等，如果按完整的走一遍三代试管流程费用一般在7-10万元左右。
