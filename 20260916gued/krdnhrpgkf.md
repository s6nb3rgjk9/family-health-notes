# 【医院动态】湖南省不孕不育规范化诊疗技术学术会议胜利召开！

> 更新时间：2026-09-16 (UTC+8)

岳麓山上书声朗，年嘉湖畔迎高朋。11月10-11号，由湖南省妇幼保健院及生殖中心主办的省继续教育项目“湖南省不孕不育规范化诊疗技术学术会议”在湖南宾馆隆重举行，大会邀请了国内外妇科内分泌及生殖医学领域的权威专家进行专题讲座与经验交流，学员主要来自于全省各个地级市基层医院的妇产科医生。11月10日上午，湖南省卫生健康委员会妇幼处王若平处长、省妇幼党委书记方超英书记、周绍明副院长、日本大阪IVF生殖中心主任福田爱作教授、北京协和医院妇产科周远征教授与邓珊教授等领导和专家出席了大会开幕式。

大会开幕式由省妇幼生殖中心主任禹虹主持，向远道而来的领导、专家及医学同仁们表示热烈的欢迎。希望本次大会为大家提供学习交流的平台，学有所值；也希望我们中心以此为契机，不断进步，为我省生殖健康与人类辅助生殖技术事业的蓬勃发展作出应有的贡献。

省妇幼党委书记方超英书记为开幕式致辞，对传经送宝的专家们以及热情学习的学员们表示热烈的欢迎和衷心的感谢。会上她对我中心提出了高要求，提升自身水平的同时还应当做好模范，为广大基层医院服务，促进全省基层医院的辅助健康事业。

省卫健委妇幼处王若平处长也为大会致辞，他首先肯定了省妇幼生殖中心的专家力量，还有感谢本次大会邀请到国内外业内的大咖，他表示这是一个极好的学习平台，机会难得，我们应加强交流，互相促进，进一步提升我省不孕不育规范化诊疗水平和推动我省辅助生殖技术的发展。

大会邀请到国内外妇产科、生殖医学领域顶级权威专家，就不同类型患者ART助孕策略、妇科内分泌基础和卵泡的发育、辅助生殖促排卵方案及药物选择、POI指南解读及助孕相关的思考、男性不育症的标准化诊断与治疗以及爱心助孕相关政策解读等热点进行全面学术交流与经验探讨。

日本大阪IVF中心主任福田爱作教授用流利的英文给我讲述了《ART strategy for various type patient》，他通过大量的图片、视频及数据让我们轻松了解到日本ART技术的发展及应用。

北京协和医院周远征教授带全体同仁一起温习了《妇科内分泌基础和卵泡的发育》，详细讲解了女性下丘脑-垂体-卵巢轴，将复杂的内分泌系统用通俗易懂的语言和案例，深入浅出的为大家进行生动有趣的讲解，并将卵泡的起源、生长、衰退以及各阶段出现问题所引发的疾病进行剖析，给生殖科、妇产科、保健科等领域的医务人员打开了一扇通往妇科内分泌缤纷世界的大门。

北京协和医院邓姗教授跟大家解读了POI指南，并对POI患者的助孕提出了相关的思考，通过生动、形象的理论讲座并结合典型病例从新颖实用的角度发表了自己独到的见解。思路清晰、浅显易懂，学员们学习的热情高涨，纷纷提问，邓教授用自己扎实的理论知识及丰富的临床经验一一给学员解惑。

湖南省妇幼保健院医学遗传科副主任席惠进一步给大家从遗传学角度进行POI患者的遗传病因学分析，层层剖析，为临床医务工作者们进行了生动案例讲解，分享了目前国内外遗传与生殖相关医学工作的宝贵经验，从而更好的为患者在遗传基因疾病方面进行有效诊疗。
